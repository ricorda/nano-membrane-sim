# 论文

读一篇论文，记下来的不是"他做了什么"，而是**你能拿它干什么**。
`templates/note-template.md` 是固定格式，每篇一份，文件名用「第一作者-年份-关键词」。

## 笔记里的五问

1. 他想解决什么问题？（一句话，不许用原文的摘要句）
2. 他用的模型/方法，最关键的假设是什么？
3. 结论里哪一条是"新"的？之前的人不知道？
4. 这个方法的边界在哪——什么情况下会失效？
5. 如果我要复现（或改一点），第一步做什么？

答不出第 5 问，说明还没读懂。
