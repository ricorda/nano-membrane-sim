# 分子动力学基础

目标：**能解释 10 个概念，能跑通 1 个例子。**

## 必须能讲清的 10 个概念

1. 分子动力学在算什么（牛顿方程 + 时间步进）
2. 力场是什么，常见的有哪些（AMBER / CHARMM / OPLS / Martini）
3. 周期性边界条件与截断半径
4. 积分步长为什么通常是 2 fs（含氢键振动）
5. 约束算法（LINCS / SHAKE）在约束什么
6. 系综：NVE / NVT / NPT，分别控制什么
7. 控温器与控压器（Berendsen / Nosé-Hoover / Parrinello-Rahman）
8. 能量最小化为什么必须在正式模拟之前做
9. 粗粒化与全原子的取舍（**尺度换细节**）
10. 什么是"跑够了"（平衡判据：能量、RMSD、回旋半径是否收敛）

## 跑通例子的验收标准

- [ ] 能在自己的机器上完成一次"蛋白质在水盒子里的模拟"（官方 tutorial 即可）
- [ ] 保留：输入文件、运行命令、`*.log` 里的性能行、一张最终结构的截图
- [ ] 能画出 RMSD 随时间的曲线，并说明它是否平衡
- [ ] 能说出这次模拟总共算了多少原子、多少纳秒、花了多久

把命令和截图写进 `env/README.md` 或单独的文件，**别人照着能复现**。

## 顺序建议

先 OpenMM（Python，几十行跑通，适合建立直觉），再 GROMACS（命令行，性能好，文献里最常见）。
