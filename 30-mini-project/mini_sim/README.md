# mini_sim：颗粒在膜上的吸附

一个纯 numpy + PIL 的二维布朗动力学脚本。不用装 Gromacs，不用装 OpenMM，
一条命令跑完出图。目的是让你先看见"吸附"这件事，再去读论文里的细节。

颗粒是一个硬圆盘，表面挂 10 条四珠子的配体链；膜是上下两条珠子链。
两者之间只有排斥和"黏附壳"，没有溶剂、没有电荷、没有第三个维度。

## 跑起来

```powershell
python sim.py          # 约 45 秒（开配体），出两张图
python sweep_kt.py     # 约 3 分钟，出降温判据那张图
```

输出：

- `fig_adsorption.png` —— 三块：间隙随时间、颗粒附近的正视图、读数
- `fig_convergence.png` —— 收敛性检查：后半段切 4 块，各自的平均形状是否重合
- `fig_cooling.png` —— 降温判据：只改温度，形变与噪声各自怎么动
- `sim_log.txt` —— 文字版读数，方便贴进周志

## 九个能调的旋钮

| 参数 | 含义 | 试试看 |
|---|---|---|
| `--eps` | 每个珠子对颗粒的吸引强度 | `2`（只贴上，压不出坑）、`12`、`40`（默认）、`120`（钻进去） |
| `--ks` | 膜的软硬，越大越硬 | `2`、`5`（默认，软）、`50`（硬） |
| `--gap` | 颗粒初始间隙 | `1.0`、`2.0`（默认）、`3.0` |
| `--kt` | 温度（约化单位） | `1`（默认）、`0.5`、`0.25`、`0.1` |
| `--nlig` | 表面挂几条配体链（每条 4 颗珠子） | `0`（光板球）、`6`、`10`（默认）、`14`（二维上限） |
| `--nolig` | 等价于 `--nlig=0` | 用来做"有配体/没配体"的对照 |
| `--twoleaf` | 让下叶也吃同一份吸引（旧做法）；**默认只让近侧上叶受吸引** | 加这个开关，看下叶那条假设值多少 |
| `--blocks` | 后半段切几块做收敛性检查 | 默认 4 |
| `--steps` | 跑多久 | `120000` 默认 |

```powershell
python sim.py --eps=120     # 吸得深到钻进去
python sim.py --ks=50       # 膜变硬，同样的吸引压不下去
python sim.py --twoleaf     # 让下叶也被吸引（旧做法），和默认组对照
python sim.py --kt=0.25     # 降温，噪声该变小
python sim.py --nolig       # 光板球：没有配体时吸附有多深
python sim.py --nlig=14     # 配体最密（二维圆盘的几何上限）
```

## 三块图在说什么

1. **上图**：颗粒底面到远处膜面的距离。从 2 nm 掉到 −0.3 左右然后停在那里——
   掉下去是吸引在拉，停住是膜的弹力加配体的排斥顶住了。
2. **左下**：颗粒附近 ±8 nm 的正视图。蓝线是膜的时间平均形状（不是某一帧，所以不抖），
   能看见颗粒底下凹下去 0.18 nm，两侧几乎不翘。黄珠是配体，它们被挤到接触点两侧。
3. **右下**：读数。默认（10 条配体）最终间隙 −0.30 nm；把配体关掉是 −0.50 nm。

## 三个自检，跑完自动打印

| 检查 | 实测 | 理论 | 说明 |
|---|---|---|---|
| 单珠热涨落 | 0.14 nm | 0.15 nm | 珠子被 K_S 拴住、K_B 抵抗弯曲，正常模式均分求和 |
| 分块收敛性 | 0.043 nm | — | 相比 0.18 nm 的信号小 4 倍；`--steps=240000` 还能再压 |
| 步长截断比例 | 0.02 % | < 1 % | 超过 1% 说明 `STEP_MAX` 太小，会压低有效温度 |

单珠涨落的理论值这样算（见 `sim.py` 的 `bead_std_theory`）：

    √⟨δz²⟩ = sqrt( (1/N) Σ_q kT / [K_S + 4·K_B·sin²(q/2)] )

注意 **√(kT/K_S) = 0.45 nm 不是单珠涨落**，它是"没有弯曲刚度时"的上界。
K_B 把短波模式压住了，真实单珠涨落只有 0.15 nm。

另外两个配体专用自检：`配体链平均首尾距` 应该在 1.8 nm 左右（伸直是 2.8），
掉到 1.0 以下说明链被压崩了；`贴膜配体珠数` 默认 6 个左右（40 颗里有一小半搭在膜上），
        超过 10 个就要怀疑穿膜了。

## 配体密度：第三个旋钮

同一套参数，只改挂几条链（跑 60000 步的快速扫描）：

| 配体链数 | 最终间隙 | 凹陷 | 说明 |
|---|---|---|---|
| 0（光板球） | −0.48 | 0.20 | 只有黏附，压得最深 |
| 6 | −0.41 | 0.24 | 配体开始撑住 |
| 10 | −0.30 | 0.14 | 默认 |
| 14 | −0.14 | 0.14 | 二维几何上限，几乎浮在膜上 |

**单调，而且方向对**：配体越多，颗粒坐得越高、坑越浅。
这就是 2018 那篇的核心结论（配体密度决定颗粒停在哪个相、能不能进去），
只不过论文里是 70/104/174 条，这里是 6/10/14 条——二维圆盘放不下更多。

（凹陷这一列在 0.14–0.24 之间跳，没有单调性：坑本来就浅，快接近分块噪声了。
间隙那一列才是可信的信号。）

## 降温判据

逻辑：**静态形变由力平衡决定，噪声的振幅 ∝ √kT。** 所以把 kT 从 1 降到 0.1：

| kT | 最终间隙 | 凹陷 | 单珠涨落（实测/理论） | 分块偏差 |
|---|---|---|---|---|
| 1.0 | −0.30 | 0.18 | 0.14 / 0.15 | 0.043 |
| 0.5 | −0.37 | 0.23 | 0.10 / 0.11 | 0.024 |
| 0.25 | −0.37 | 0.24 | 0.07 / 0.07 | 0.015 |
| 0.1 | −0.38 | 0.25 | 0.05 / 0.05 | 0.008 |

两件事同时成立：

1. **噪声按 √kT 掉**，每个温度都和理论吻合到 0.01 nm 以内。温度接对了，
   噪声没有第二个来源。
2. **凹陷只从 0.18 变到 0.25**（+39%），而噪声掉到原来的 1/3。这点形变是真的，不是噪声堆出来的。

凹陷随降温反而变深，方向和"没有配体"时相反，这不是矛盾：**配体是熵弹簧**。
温度高时它靠构象熵撑开、把颗粒顶住；温度一低，熵的贡献小了，颗粒就坐得更低。
没有配体时看到的才是另一条：温度低、膜变硬，坑变浅（`sweep_kt.py --nolig`：0.21 → 0.18）。
两个效应都是熵，符号相反。

## v0.3 加配体时修掉的三个问题

1. **配体会从膜珠子的缝里漏过去**：珠子间距 1.0 nm，配体直径 0.7 nm。
   先试的"配体珠子 vs 膜珠子"两两排斥根本堵不住，链子会挂到膜的另一侧。
   改成把膜当**有厚度的软墙**：线性插值出配体脚下膜的高度，按垂直距离排斥，
   反作用按 (1−w, w) 摊到相邻两颗珠子上。
2. **锚点在膜里面**：颗粒吸附后下半球的锚点本来就在膜里。加了"陷进两叶之间就往近侧推出去"这条，
   并且给了反作用——不给反作用时，配体子系被凭空喂力，20 条链的颗粒会以 +160 nm 飞走。
3. **二维装不下那么多链**：锚点排在半径 R 的圆周上，链距不能小于珠子直径，
   上限是 2πR/0.7 ≈ 14 条。超过就自动截到 14 并打印提示。真实三维里同一面积能放更多。

顺带做的：吸引势在 `[R+CUT−0.6, R+CUT]` 之间乘一个光滑开关，力从 1.99 平滑降到 0
（原来在 4.3 nm 处直接跳断，颗粒会"踩空"）。代价是尾部少了一截拉力，无配体时默认间隙
从 −0.73 变成 −0.68（这 0.05 就是原来那个假力的贡献）；后来默认改成单叶，又变成 −0.50。

## v0.2 修掉的四个问题（都是自查出来的）

1. **x 分量串进了 z 力**：`f_out[i] += mag*ux` 是多余的——珠子只有 z 自由度。
   这行让左右两侧的珠子多受了大小相等、方向相反的力，于是形变左右不对称，
   还凭空造出一个"周围隆起"。删掉后形变严格左右对称。
2. **颗粒的 x 放在珠子上**（32.0），而不是晶格中心（31.5）——左右珠子数差一个。
   已改为 `(N_COL-1)*A/2`。
3. **初始间隙 3.0 在吸引范围外**：R+CUT = 4.3 nm，gap=3.0 时最近珠距 4.6 nm，
   于是开头有一段"自由扩散"，seed=2 时颗粒直接飘走。默认改为 2.0。
4. **物理注释写错**：吸引是 `exp(-(d-R)/W)`（指数），不是高斯。

## 这个模型故意没做的事

- 只有两维，珠子只能上下动，不能侧向让开——真实体系里颗粒会被"包"起来，这里只能压出坑
- 配体只有 4 颗珠子、3 个键，没有电荷、没有质子化，所以做不了 2024 那篇的 pH 效应
- 没有溶剂：时间单位不对应真实纳秒，**只能比趋势，不能报绝对时间**
- 盒子两边开放，膜可以整体倾斜（用线性去趋势扣掉了）
- 二维圆盘最多 14 条配体链，真实三维的配体密度扫不到

## 一个模型选择：下叶要不要被吸引

默认**只让近侧上叶受吸引**：颗粒从上方靠近，隔着 2.4 nm 的疏水核心，
远端那一叶不该吃到同一个范德华吸引。`--twoleaf` 可以退回旧做法，两者差这么多：

| 组 | 只近侧叶（默认） | 两叶都吸引（`--twoleaf`） | 差 |
|---|---|---|---|
| 无配体 | −0.50 / 0.21 | −0.68 / 0.31 | 0.18 nm |
| 10 条配体 | −0.30 / 0.18 | −0.38 / 0.24 | 0.08 nm |

无配体时这条简化值 0.18 nm（约 26%），有配体时只值 0.08 nm——因为颗粒本来就被配体顶高了，
下叶那点额外吸引没那么关键。真实情况未必是零：下叶隔着疏水核心，作用应该被大幅削弱，
但不至于完全没有。所以**默认单叶是"偏保守"的选择**，把吸附算浅一点而不是算深一点。
