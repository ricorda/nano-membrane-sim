# 小课题

> **当前选定：`PROJECT.md` —— 纳米颗粒在膜上的吸附 + 代理模型。**
> 下面三个候选保留作备选，别再另起炉灶。

目标：**4–6 周内做出一个能给别人看的结果**，哪怕很小。
标准不是"有新意"，是"完整"：有目标、有方法、有图、有结论、有局限。

## 三个候选（按难度排）

### 候选 1：二维补丁粒子的逆向设计（推荐）

把 ACS Nano 那篇的三维流程降到二维：

- 目标结构：正方形镶嵌 / 六边形（蜂窝）镶嵌
- 设计变量：每个粒子表面的补丁方位角（离散）+ 结合强度（连续）
- 搜索：先用遗传算法搜方位，再用网格/随机搜索搜强度（二维不需要贝叶斯优化）
- 评价：跑一段短模拟，看目标结构是否保持

交付：代码 + 一张"得分随代数上升"的曲线 + 一张最优方案的构型图。

**为什么推荐**：计算量小（一台笔记本能跑），逻辑和论文一致，讲起来清楚。

### 候选 2：形状对穿膜的影响（复现性）

用公开的粗粒化模型（如 Martini）搭一个简单膜 + 一个球形/棒状颗粒，比较两者进入膜所需的时间或自由能。

交付：两条自由能曲线 / 两张轨迹截图 + 对比结论。

**风险**：自由能计算（umbrella sampling）对新手偏难，容易卡在收敛上。

### 候选 3：文献计量小分析

把某一个方向的论文抓下来，做关键词共现、时间演化、合作网络。

交付：三张图 + 一段"他的研究重心怎么变的"分析。

**风险**：和"模拟分子"关系较远，更像是调研而不是研究。

## 时间表（以候选 1 为例）

| 周 | 任务 | 交付 |
|---|---|---|
| 1 | 读论文方法部分，写清数据结构和能量/评分定义 | 半页设计文档 |
| 2 | 实现"给定参数 → 跑模拟 → 返回得分"的评估函数 | 能跑通的最小闭环 |
| 3 | 加遗传算法，跑出收敛曲线 | 曲线图 |
| 4 | 调参、做对照（随机搜索）、写一页说明 | 结果 + 说明 |

## 一页说明的模板

1. 我想做什么（一句话）
2. 我怎么做的（方法 + 关键参数）
3. 我得到了什么（图 + 数字）
4. 哪里可能不对（局限）
5. 下一步可以做什么
