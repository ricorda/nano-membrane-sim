# mini_sim：颗粒在膜上的吸附

一个 200 行的二维布朗动力学脚本，只用 numpy + PIL。不用装 Gromacs，不用装 OpenMM，
双击就能跑出图。目的是让你先看见"吸附"这件事，再去读论文里的细节。

## 跑起来

```powershell
python sim.py
```

输出两个文件：

- `fig_adsorption.png` —— 三块：间隙随时间、颗粒附近的正视图、读数
- `sim_log.txt` —— 同样内容的文字版，方便贴进周志

## 四个能调的旋钮

| 参数 | 含义 | 试试看 |
|---|---|---|
| `--eps` | 每个珠子对颗粒的吸引强度 | `2`（只贴上，压不出坑）、`40`（默认）、`120`（钻进去） |
| `--ks` | 膜的软硬，越大越硬 | `5`（默认，软）、`20`、`50`（硬） |
| `--gap` | 颗粒初始离膜多远 | `1.0`、`3.0`（默认）、`6.0` |
| `--steps` | 跑多久 | `120000` 默认，约 9 秒 |

```powershell
python sim.py --eps=120     # 吸得深到钻进去
python sim.py --ks=50       # 膜变硬，同样的吸引压不下去
```

## 三块图在说什么

1. **上图**：颗粒底面到远处膜面的距离。从 3 nm 掉到 0 附近然后一直停在那里——
   掉下去是吸引在拉，停住是膜的弹力顶住了。
2. **左下**：颗粒附近 ±8 nm 的正视图。蓝线是膜的时间平均形状（不是某一帧，所以不抖），
   能看见颗粒底下凹下去 0.39 nm，两侧微微翘起。
3. **右下**：读数。最终间隙 −0.71 nm 是负的，意思是颗粒已经压到原来膜面以下。

## 这个模型故意没做的事

- 只有两维，珠子只能上下动，不能侧向让开——真实体系里颗粒会被"包"起来，这里只能压出浅坑
- 没有配体、没有电荷、没有溶剂，颗粒就是一个光滑硬球
- 一个时间单位不对应真实的纳秒，所以**只能比趋势，不能报绝对时间**
- 盒子两边是开放的，膜可以整体倾斜（用线性去趋势扣掉了）

这些正是后面要补的东西：先把 `--eps` 扫一遍出曲线，再决定补哪一个。
