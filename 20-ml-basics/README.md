# 机器学习最小基础

目标不是"学完机器学习"，而是**能读懂论文里的优化流程，并且自己实现一个能跑的小版本**。

## 按需要学，顺序如下

1. **numpy**：数组、广播、随机数、`np.linalg`
2. **matplotlib**：折线、散点、误差棒、多子图、中文标签
3. **pandas**：读 csv、groupby、简单的描述统计
4. **sklearn**：线性回归、随机森林、train/test split、交叉验证
5. **PyTorch**：张量、自动求导、一个训练循环（前向 → loss → 反向 → step）
6. **概念**：过拟合与正则化、偏差-方差、代理模型（surrogate model）、采集函数（acquisition function）

## 和这个方向直接相关的三个概念

- **代理模型（surrogate model）**：用便宜的函数去近似昂贵的模拟。论文里用高斯过程做贝叶斯优化的代理。
- **采集函数（acquisition function）**：在"已知的好地方附近再找"和"去没试过的地方看看"之间权衡（exploitation vs exploration）。
- **遗传算法（GA）**：种群、适应度、选择、交叉、变异。适合离散、组合爆炸的搜索空间。

## 验收标准

- [ ] 能手写一个线性回归（梯度下降，不用 sklearn），画出 loss 曲线
- [ ] 能用 matplotlib 画出一张带中文标签、带图例、可直接放进报告的图
- [ ] 能实现一个 20 行的遗传算法，优化一个一维函数
- [ ] 能说清"为什么贝叶斯优化比网格搜索省模拟次数"
